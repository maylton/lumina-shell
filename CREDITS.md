# Credits and third-party references

Lumina Shell is an original Niri-first implementation maintained by Maylton and the Lumina Shell contributors.

The project learns from the wider Wayland desktop ecosystem:

- [Quickshell](https://github.com/quickshell-mirror/quickshell), licensed under the GNU LGPL v3, provides the Qt/QML shell runtime and public APIs used by Lumina.
- [noctalia-qs](https://github.com/BAZAndreas/noctalia-qs), licensed under the GNU LGPL v3, is the validated Quickshell fork used on CachyOS.
- [Sleex](https://github.com/AxOS-project/Sleex), licensed under the GNU GPL v3, is an architectural and interaction reference for modular shell surfaces and dashboard composition.
- [Noctalia](https://github.com/noctalia-dev/noctalia), licensed under the MIT License, is a reference for cohesive Wayland shell workflows.
- [Material Design 3](https://m3.material.io/) is a design-system reference for semantic color, shape, spacing, typography, and motion.

At the time of this notice, Lumina does not include source code, artwork, icons, logos, or other assets copied from Sleex or Noctalia. Similar concepts are implemented independently for Lumina's own Niri-first architecture and visual language. Runtime libraries and system-provided icons remain governed by their respective licenses.

Future contributions that incorporate third-party material must preserve the original copyright and license notices and document the material here.
